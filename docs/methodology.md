## 3 定义

设 $F$ 为关注名单，$V$ 为认证粉丝名单，$P$ 为样本推文集合。用户名统一进行规范化处理：去除 @ 及前后空格，统一转为小写后去重。

**关系集合：**

$$M = F \cap V,\qquad N = F \setminus V,\qquad O = V \setminus F$$

- $M$：互关
- $N$：我关注、但不在认证粉丝里
- $O$：认证粉丝里、我没关注的

**账号互动量：** 对账号 $u$，

$$e(u) = \sum_{p \in P}\big(L_{u,p} + R_{u,p} + Q_{u,p} + S_{u,p}\big)$$

其中 $L$、$R$、$Q$、$S$ 分别是点赞、回复、引用、转帖次数。

**零互动率：** 对任意集合 $S$，

$$Z(S) = \frac{\lvert\{u \in S : e(u) = 0\}\rvert}{\lvert S \rvert}$$

**互关率：**

$$m = \frac{\lvert M \rvert}{\lvert V \rvert}$$

**互动者分层：** 互动频次较低时容易出现大量并列，直接按名次截取「前 15」波动较大，因此改用门槛阈值进行分层：

$$E_k = \{u : e(u) \ge k\},\quad k = 1, 2, 3$$

**互关特征标记：** 满足以下任一条件，$\mathrm{flag}(u)=1$：

- 名字或简介命中关键词表（附录 A），按「包含」匹配，不区分大小写；
- 账号在 D4 中出现。

**有效曝光的形式化定义（依据第 2 节规则，用于理论讨论，本文未作直接测量）：** 设 $i$ 为一次曝光，$v(i)$ 是观看者，$s(i)$ 是曝光出现的位置，$p(i)$ 是被看的帖子。资格门槛计数为

$$I_{\text{elig}} = \sum_{i}\mathbf{1}\big[v(i)\ \text{已认证}\big]\cdot\mathbf{1}\big[s(i) = \text{首页时间线}\big]\cdot\mathbf{1}\big[p(i)\ \text{不是回复}\big]$$

窗口为最近 90 天，门槛为 $I_{\text{elig}} \ge 500{,}000$。收益依据的合格曝光则是对 $(v, p)$ 去重后计数，并要求 $v$ 是 Premium 用户、帖子至少 50% 可见，且不是付费、推广或欺诈曝光。
